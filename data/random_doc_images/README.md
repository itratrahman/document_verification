# Random Document Images Directory

This directory contains random document images organized by document type for the document verification project.

## Subdirectories

- **blank_pages/** - Blank document pages
- **book_front_covers/** - Book front cover images
- **book_pages/** - Book page images
- **books/** - Book images
- **driving_license/** - Driving license document images
- **invoice/** - Invoice document images
- **letters/** - Letter document images
- **national_certificates/** - National certificate document images
- **newspapers/** - Newspaper document images
- **passport/** - Passport document images
- **tax_documents/** - Tax document images

## Purpose
These random document images serve as negative examples in the document verification classification task, helping the model distinguish between actual licenses and other document types.
