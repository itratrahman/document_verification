# Truth Tables Directory

This directory contains JSON truth table files corresponding to the generated license images in the Original directory.

## Contents
- JSON metadata files in the pattern `generated_license_*.json`
- Total files: ~3000+ JSON files

## Purpose
- Ground truth annotations for the generated license images
- Used for validating model predictions and evaluating accuracy
- Contains metadata and expected classification labels

## File Format
Each JSON file contains metadata associated with its corresponding PNG image.
